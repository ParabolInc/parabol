# Offboarding checklist

Complete these steps on or before a teammate's last day. The manager owns the list and the people team supports.

- [ ] Remove access to the code repository, chat workspace and shared drives at the end of the last day
- [ ] Revoke the password manager seat and single sign-on account
- [ ] Collect the laptop, badge and any other hardware, or send a prepaid return label to remote teammates
- [ ] Transfer ownership of documents, dashboards and open pull requests
- [ ] Hand over on-call shifts and update the rotation
- [ ] Schedule the exit interview with the people team
- [ ] Remove them from mailing lists and recurring calendar events
- [ ] Send a farewell note to the team and thank them for their work
