# Onboarding checklist

Everything a new teammate needs to get started during the first week.

- [ ] Laptop setup: install the disk encryption profile, then sign in to the password manager
- [ ] Ask your manager for access to the code repository, the chat workspace and the shared calendar
- [ ] Have coffee with your onboarding buddy and take the product tour
- [ ] Read the engineering handbook and the on-call guide
- [ ] Ship one small change to production before Friday
